# Calculadora de Média
Uma simples calculadora de médias escolares


# Linguagem Utilizada:
Python 3.14.6

# Como Instalar e Executar:
Executar através de IDS instalada em sua máquina ou através de compiladores online, ex: [MyCompiler](https://www.mycompiler.io/pt)

# Exemplo de Uso ou Demonstração: 
```=== Sistema de Notas do Aluno ===```
```Digite a primeira nota: 7.5```
```Digite a segunda nota: 8```
```A média final é: 7.75```
